換頁時焦點會移到頁面標題（讓讀屏讀出新頁面）。標題不是可操作元件，不畫外框；可操作的元件才有焦點環。

客戶 陳雅婷

[tabindex="-1"]:focus { outline: none; box-shadow: none; }   /* h1、main 等程式聚焦的目標 */
:focus-visible { box-shadow: var(--focus-ring); }              /* 按鈕、連結、輸入框：鍵盤操作時才顯示 */
