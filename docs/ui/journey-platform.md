## 狀態
| 畫面 | 空 | 載入中 | 錯誤 | 成功 |
|---|---|---|---|---|
| 登入 | 空白表單；欄位為空 400：「請輸入 Email。」 | 欄位唯讀、按鈕「登入中…」 | 401：「Email 或密碼不正確。」（唯一一句）；429：「登入失敗次數過多，這個 Email 暫時無法登入。請在 N 分 N 秒後再試。」按鈕停用 | 回原頁；逾時顯示「登入已逾時，請重新登入。」 |
| 修改密碼 | 空白 | 按鈕停用 | 401 舊密碼錯：欄位下「目前密碼不正確。」（不導向登入）；400：「新密碼長度須為 12 到 72 字元…」 | 「密碼已更新。其他已登入的裝置不會被登出。」 |
| 旅程列表 | v0.2.0：「還沒有旅程」並說明由團隊協助建立；v0.3.0 編輯者有建立鈕；篩選無結果：清除搜尋 | 骨架列 | 紅色提示＋`request_id`＋重試 | 表格＋載入更多（cursor） |
| 旅程頁／畫布 | — | 骨架 | 404「找不到這個旅程」；5xx 重試 | 圖＋面板 |
| 客戶搜尋 | 初始列出可輸入內容；查無：列可能原因 | 「搜尋中…」 | 空字串 400：「請輸入要搜尋的內容。」；5xx 重試 | 結果表（遮罩徽章） |
| 客戶頁／軌跡 | 尚無旅程：說明何時出現 | 骨架 | 404 與 5xx 分開；旅程紀錄失敗只影響該區塊；定義取得失敗退回逐步紀錄 | 終態另顯示結束時間與原因 |
錯誤碼文案：`FORBIDDEN`「你的角色（X）不能使用這項功能」；`CSRF_INVALID` 重取 `/auth/me` 自動重試一次，仍失敗「操作未完成，請重新整理頁面」；`DRAFT_CONFLICT`「草稿已被 X 在 HH:mm 修改」（先 GET draft 取 `updated_by`）；`JOURNEY_ABORTED`「這個旅程已停止，不能再修改或發佈」；`JOURNEY_NOT_PUBLISHED`「尚未發佈的旅程無法停止」；`DRAFT_REQUIRED`「草稿狀態的旅程不能刪除草稿」；`INTERNAL_ERROR`／`SERVICE_UNAVAILABLE` 附 `request_id` 與重試。
## 互動
| 操作 | 結果 | 回饋 |
|---|---|---|
| 搜尋客戶 | 網址同步 `?q=`；一筆直進客戶頁並顯示「搜尋『…』比對到這位客戶（比對方式：email）」 | 完成後焦點到結果標題；客戶頁焦點到 h1 |
| 角色 | 檢視者：只能看，編輯／停止鈕停用並以 `aria-describedby` 說明；編輯者：編輯、送審、撤回、停止；管理員：另可核准、退回（D-056） | 停用鈕仍可聚焦並讀出原因 |
| 編輯 | 在最新版本上建立草稿（`revision` 0）；加節點用「加入」或拖曳；連線用下拉或拖曳 | 圖上紅框＋「⚠ 有錯誤」，面板「定位節點」；`node_id` 為 null 的項目改「前往旅程設定」 |
| 送審 | 驗證通過才可送；草稿鎖定唯讀；對話框可填說明（選填 200 字） | 「已送審，等待管理員審核。」焦點回頁首 |
| 核准並發佈 | 確認後發佈新版（新進入者用新版、既有客戶不變） | 「已核准並發佈 vN。」 |
| 退回 | 原因必填 1–200 字；送審者看到原因並可修改後再送審 | 空白：「請填寫退回原因」，對話框保留 |
| 停止旅程 | 原因必填；立即不收新客戶，進行中客戶背景轉已中止 | 「已停止。進行中的客戶會陸續轉為已中止。」 |
D-060 建議的畫法：管理員送審者看到「不能核准自己送審的版本，請另一位管理員審核」；每次發佈都審（含已上線旅程發新版，核准前仍是舊版上線）；停止不審核。
## 圖形、迴圈與遮罩
- 節點三態：已經過＝綠框＋「✓ 已經過」；目前位置＝琥珀粗框＋「● 目前位置」；未經過＝虛線框（讀屏「未經過」）。迴圈：回邊畫在節點下方繞回的點狀線標「再等一輪」；同節點多次經過標「步驟 6、8」，逐步紀錄標「第 2 次經過」；畫布與編輯另在圖上方顯示迴圈提醒（D-050，不限圈數）
- 出口（`out_port`）：逐步紀錄寫「出口：no（否）」；分支連線標出口名稱（是／否、事件發生／逾時、分組顯示名稱）；SendMessage 的出口是 `sent`
- 遮罩沿用 v0.1.0：只有後端標記（`masked`、`masked_paths`）的值顯示「已遮罩」，無法解除、不提供複製；姓名等屬性不在白名單時也遮罩，客戶頁標題因此用客戶 ID（長 ID 只顯示頭尾，完整值在客戶頁並可複製）
## 窄螢幕與無障礙
- 1024px 以下側欄改頂列；1100px 以下兩欄改單欄；640px 以下表格轉卡片、篩選堆疊、互動元件高 >= 44px（#66）、對話框滿版寬、圖左右捲動並提示改看文字版。畫布編輯建議桌面；窄螢幕保證可檢視與審核，連線可用下拉完成。登入欄位間距已修（#51）
- 對比：文字 >= 4.5:1、邊框與圖形 >= 3:1；狀態一律有文字。鍵盤：圖卡片是 `<button aria-pressed>`，拖曳皆有替代操作，縮放 + / − / 0；對話框 `role="dialog" aria-modal`，焦點進入並回到觸發鈕，Esc 取消。讀屏：圖 `role="group"`、邊與裝飾 `aria-hidden`、軌跡用 `<ol>` 且目前步驟 `aria-current="step"`、載入 `role="status"`、錯誤 `role="alert"`、429 倒數只在開始時朗讀；尊重 `prefers-reduced-motion`
