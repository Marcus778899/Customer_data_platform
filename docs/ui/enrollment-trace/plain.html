發送歷史

尚無發送紀錄。

  1. Enrollment、as_of、輪詢間隔：系統內部名詞，使用者不知道要不要在意。
  2. WaitDelayNode · wait_1、出口：—：程式的節點型別與連接點名稱。
  3. P3D、2026-10-21T02:00:00Z：ISO 格式與 UTC，要自己換算成幾天、幾點。
  4. 兩串 26 碼 ID 在標題下：佔最醒目位置，卻不是行銷、業務在意的資訊。
  5. 「目前狀況」一句話：只有「在哪」，沒有「接下來」「有沒有收到」，要往下找。
