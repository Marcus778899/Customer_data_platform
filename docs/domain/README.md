## 核心規則

- 每次發佈都要另一位管理員核准，送審者不可核准自己的；停止不審核（rules.md「審核」，D-056、D-060）
- 送審中草稿鎖定；退回必附原因，改完可再送審（rules.md「審核」，D-056）
- 管理金鑰可直接建立版本並自動留紀錄，各環境可關閉（rules.md「審核」#8，D-061）
- 草稿只能由登入的編輯者以上操作；刪除草稿即放棄，新草稿不帶舊的退回狀態（rules.md「審核」#9、#10）
- 客戶綁定進入當下的版本，新版本不影響已在旅程中的客戶（rules.md「版本綁定」，spec 02 §2）
- 停止立即生效、未送出的訊息取消、不可恢復（rules.md「停止」，D-060）
- 迴圈允許不限圈數，但必須含等待節點（rules.md「節點」，D-050）
- 分流只分組、不做成效分析（rules.md「節點」，#157）
- 遮罩採白名單，內建明文只有姓名（rules.md「遮罩」，D-021、D-082、#184；`.env` 選填可取代，D-083）
- 第二版驗收以縮減版場景一（rules.md「驗收場景」，D-046）
